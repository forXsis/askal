# Askal — Полное руководство по языку

**Версия:** 1.8.0
**Дата:** 2026

Askal — статически типизированный компилируемый язык программирования
с собственным компилятором, байткодом и лёгкой виртуальной машиной.

Этот документ описывает **весь язык целиком**. Прочитав его, можно
писать программы на Askal без дополнительной документации.

## 1. Введение

Askal — **стек-ориентированный** компилируемый язык. Программа
компилируется в байткод (`.aklp`), который исполняется виртуальной
машиной. Опционально байткод можно упаковать в автономный `.exe`.

**Ключевые особенности:**

- Статическая типизация с выводом типов (`auto`, `int`).
- Объектно-ориентированное программирование.
- Встроенные коллекции (`list`, `dict`, `array`) с автоматическим
  управлением памятью (ref-counting GC).
- Обработка исключений (`try` / `catch` / `finally` / `throw`).
- Нативные библиотеки (`.dll`) для расширения возможностей.
- Простой синтаксис, вдохновлённый C, Python и C#.

## 2. Hello, World!

```askal
use console;

console >> println("Hello, World!");
```

Компиляция и запуск:

```
askal_compiler --c hello.akl
askal_vm --r hello.aklp
```

**Разбор:**
- `use console;` — подключает библиотеку `console.dll`.
- `console >> println(...)` — вызов функции `println` из библиотеки.
- Оператор `>>` — доступ к функции/методу.

## 5. Переменные

```askal
// С инициализацией
var int64 x = 10;
var str   name = "Askal";
var bool  flag = true;

// Без инициализации — значение по умолчанию (0, "", false)
var int64 counter;

// AUTO — тип выводится из правой части
var auto a = 42;             // сейчас int64
a = "теперь строка";         // стало str
```

### Присваивание

```askal
x = 20;

x += 5;   // x = x + 5
x -= 3;   // x = x - 3
x *= 2;   // x = x * 2
x /= 4;   // x = x / 4
x %= 4;   // x = x % 4

x++;      // x = x + 1
x--;      // x = x - 1
```

### Область видимости

Переменные, объявленные в блоке `{}`, видны только внутри.
Внешние видны внутри. Можно перекрывать (shadowing):

```askal
var int64 x = 100;

for (var int64 x = 0; x < 3; x = x + 1) {
    // здесь x = 0, 1, 2
}

// здесь x всё ещё 100
```

## 7. Операторы

### Арифметика

| Оператор | Описание       | Пример    | Результат |
|----------|----------------|-----------|-----------|
| `+`      | сложение       | `10 + 3`  | `13`      |
| `-`      | вычитание      | `10 - 3`  | `7`       |
| `*`      | умножение      | `10 * 3`  | `30`      |
| `/`      | деление        | `10 / 3`  | `3`       |
| `%`      | остаток        | `10 % 3`  | `1`       |
| `-x`     | унарный минус  | `-5`      | `-5`      |

Деление целых — целочисленное. Деление на ноль возвращает 0.

### Сравнения

| Оператор | Описание             |
|----------|----------------------|
| `==`     | равно                |
| `!=`     | не равно             |
| `<`      | меньше               |
| `>`      | больше               |
| `<=`     | меньше или равно     |
| `>=`     | больше или равно     |

Строки сравниваются лексикографически.

### Логические

| Оператор | Описание |
|----------|----------|
| `&&`     | И        |
| `\|\|`   | ИЛИ      |
| `!`      | НЕ       |

### Тернарный

```askal
var int64 min = (a < b) ? a : b;
```

### Конкатенация строк

При `+` с одной строкой второй операнд конвертируется в строку:

```askal
var str s = "n = " + 42;      // "n = 42"
var str t = "flag=" + true;   // "flag=true"
var str u = 7 + " items";     // "7 items"
```

### `>>` — доступ к члену

Оператор `>>` используется для вызова функций из библиотек,
методов объектов и доступа к полям:

```askal
console >> println("hi");     // native-функция
obj >> method();              // метод объекта
var int64 x = obj >> field;   // поле объекта
obj >> field = 5;             // присваивание поля
```

**Важно:** `>>` — не битовый сдвиг. Битовых операторов в Askal нет.

## 8. Управляющие конструкции

### if / else if / else

```askal
if (x > 0) {
    console >> println("positive");
} else if (x < 0) {
    console >> println("negative");
} else {
    console >> println("zero");
}
```

### while

```askal
var int64 i = 0;
while (i < 10) {
    console >> print_int(i);
    i = i + 1;
}
```

### for

```askal
// классический
for (var int64 i = 0; i < 10; i = i + 1) {
    console >> print_int(i);
}

// без условия (бесконечный)
for (var int64 i = 0; ; i = i + 1) {
    if (i >= 5) { break; }
}

// без init
var int64 j = 0;
for (; j < 5; j = j + 1) { }
```

### switch

```askal
switch (day) {
    case 1: console >> println("Mon");
    case 2: console >> println("Tue");
    default: console >> println("other");
}
```

**Fall-through отсутствует.** После выполнения case управление
уходит в конец `switch`. `break` не нужен и не поддерживается
внутри `switch` в версии 1.8.0.

### break / continue

```askal
for (var int64 i = 0; i < 100; i = i + 1) {
    if (i > 10)     { break; }
    if (i % 2 == 0) { continue; }
    console >> print_int(i);
}
```

Работают только внутри `while` / `for`.

fun greet(str name) {

// С возвращаемым значением — стрелка ->

### Вызов

```askal
greet("World");
var int64 s = add(3, 4);
```

### Рекурсия

```askal
fun fact(int64 n) -> int64 {
    if (n <= 1) { return 1; }
    return n * fact(n - 1);
}
```

### Forward reference

Функцию можно вызывать до её объявления:

```askal
fun a() -> int64 { return b(); }
fun b() -> int64 { return 42; }
```

## 10. Классы и объекты

### Объявление

```askal
class Point {
    var int64 x = 0;
    var int64 y = 0;

    fun init(int64 x0, int64 y0) {
        x = x0;
        y = y0;
        return null;
    }

    fun translate(int64 dx, int64 dy) {
        x = x + dx;
        y = y + dy;
        return null;
    }

    fun length_sq() -> int64 {
        return x * x + y * y;
    }
}
```

### Создание объекта

```askal
var Point p = Point(3, 4);
```

**Особенность 1.8.0:** `init()` вызывается **только если в вызове есть
аргументы**. `Point()` без аргументов создаёт объект с дефолтными
полями и **не** вызывает `init`.

### Доступ к полям и методам

```askal
var int64 vx = p >> x;         // чтение поля
p >> x = 10;                   // запись поля
p >> translate(5, 5);          // вызов метода
var int64 len = p >> length_sq();
```

### self

Внутри метода `self` — это объект-получатель. Обращение к полю
**неявно** идёт через `self`:

```askal
class Counter {
    var int64 n = 0;

    fun init(int64 start) {
        n = start;             // = self >> n = start
        return null;
    }

    fun inc() {
        n = n + 1;             // = self >> n = self >> n + 1
        return null;
    }

    fun get() -> int64 {
        return n;              // = return self >> n
    }
}
```

Явно:

```askal
fun double() -> int64 {
    return self >> get() + self >> get();
}
```

Внутри метода вызов другого метода класса без `obj >>` работает
как вызов через `self`.

### Объекты как аргументы и возвраты

```askal
fun dot(Point a, Point b) -> int64 {
    return (a >> x) * (b >> x) + (a >> y) * (b >> y);
}

fun makePoint(int64 x, int64 y) -> Point {
    return Point(x, y);
}
```

### Освобождение объектов

```askal
p >> free();
```

`free()` **обнуляет переменную** и снимает ссылку на объект.
Объект удаляется автоматически, когда на него не остаётся ссылок
(ref-counting GC). **Двойной `free()` безопасен.**

## 11. Коллекции

### list — динамический список

```askal
var list xs = [10, 20, 30];

var int64 first = xs[0];        // чтение
xs[1] = 99;                     // запись

xs >> push(40);                 // добавить в конец
var int64 p = xs >> pop();      // снять с конца
xs >> insert(0, 5);             // вставить по индексу
xs >> remove(0);                // удалить по индексу
xs >> clear();                  // очистить

var int64 n = len(xs);          // длина
var int64 m = xs >> len();      // то же
```

### dict — словарь str → значение

```askal
var dict d = {"name": "Askal", "version": 18};

var auto v = d["name"];
d["version"] = 19;

if (d >> has("name")) { /* ... */ }
d >> remove("version");

var list keys = d >> keys();      // список ключей
var list vals = d >> values();    // список значений

var int64 n = len(d);
```

**Ключи — только строки.**

### array — массив фиксированной длины

```askal
var array arr = [0, 0, 0, 0, 0];

arr[2] = 42;
var int64 v = arr[2];

arr >> fill(7);                 // заполнить все элементы
var int64 n = len(arr);
```

**В array нельзя `push`/`pop`/`insert`/`remove`** — длина фиксирована
при создании.

### Вложенность

```askal
var dict cfg = {"nums": [1, 2, 3]};

var list inner = cfg["nums"];
console >> print_int(inner[0]);
```

### Итерация

```askal
var list xs = [10, 20, 30];
for (var int64 i = 0; i < len(xs); i = i + 1) {
    console >> print_int(xs[i]);
}

var dict d = {"a": 1, "b": 2};
var list keys = d >> keys();
for (var int64 i = 0; i < len(keys); i = i + 1) {
    console >> println(keys[i]);
    console >> print_int(d[keys[i]]);
}
```

**Замечание:** `for-in` пока не реализован — используйте
индексный цикл.

### Встроенные методы коллекций

| Метод     | Где применяется      | Что делает                        |
|-----------|----------------------|------------------------------------|
| `push`    | list                 | добавить элемент в конец          |
| `pop`     | list                 | снять и вернуть последний элемент |
| `insert`  | list                 | вставить по индексу               |
| `remove`  | list                 | удалить по индексу                |
| `clear`   | list, dict           | очистить                          |
| `fill`    | array                | заполнить все элементы            |
| `has`     | dict                 | проверить ключ                    |
| `keys`    | dict                 | список ключей                     |
| `values`  | dict                 | список значений                   |
| `len`     | list, array, dict    | длина                              |

## 12. Исключения

### try / catch / finally

```askal
try {
    throw 42;
} catch (e) {
    console >> println("caught");
} finally {
    console >> println("cleanup");
}
```

Обязательно должен быть **хотя бы один** из блоков `catch` или
`finally`.

### throw

```askal
throw 42;
throw "error message";
throw someVar;
```

Бросать можно значение **любого типа**.

### Вложенные try

```askal
try {
    try {
        throw 1;
    } catch (e) {
        throw 2;
    }
} catch (e) {
    // перехватит 2
}
```

### Uncaught exceptions

Если `throw` вызван без активного `try`, программа завершается
с сообщением `Uncaught exception: ...`.

## 15. Компиляция и запуск

### Компиляция

```
askal_compiler --c file.akl                # → file.aklp
askal_compiler --c file.akl -o out.aklp    # свой путь
askal_compiler --c file.akl -v             # подробно
askal_compiler --c file.akl --dump         # hex-дамп байткода
askal_compiler --c file.akl -O0            # без оптимизации
askal_compiler --c file.akl -O1            # constant folding (по умолчанию)
askal_compiler --c file.akl -O2            # + peephole
```

### Запуск

```
askal_vm --r file.aklp                     # запустить
askal_vm --r file.aklp -v                  # verbose
askal_vm --r file.aklp --trace             # трассировка опкодов
askal_vm --r file.aklp --dump              # вывести глобалы после
```

### Уровни оптимизации

| Уровень | Что делает                                             |
|---------|---------------------------------------------------------|
| `-O0`   | Ничего. Прямая генерация.                                |
| `-O1`   | Constant folding (сворачивание константных выражений).   |
| `-O2`   | `-O1` + peephole (удаление бесполезных инструкций).      |

По умолчанию — `-O1`.

**Пример:** `var int64 x = 2 + 3 * 4;` при `-O1` → `PUSH 14`,
при `-O0` → `PUSH 2; PUSH 3; PUSH 4; MUL; ADD`.

## 16. Упаковка в .exe

`askal_pack` собирает автономный `.exe`: виртуальная машина +
байткод + нужные `.dll` в одном файле.

```
askal_pack --input program.aklp --output program.exe --all-libs --libs-path tools
```

Затем `program.exe` запускается двойным кликом, без VM и DLL рядом.

**Замечания:**
- `pack_vm.exe` должен лежать рядом с `askal_pack.exe`.
- Все `.dll`, указанные в `use`, будут встроены.
- При запуске `.exe` распаковывает `.aklp` и `.dll` во временную
  папку `%TEMP%\askal-pack-run`.

## 19. Ограничения и планы

### Чего нет в 1.8.0

- **`for-in`** по коллекциям — используйте индексный цикл.
- **Наследование классов.**
- **Интерфейсы, generics, шаблоны.**
- **Лямбды, замыкания.**
- **Многопоточность.**
- **Битовые операторы** (`&`, `|`, `^`, `<<`).
- **Модули / namespace.**
- **Пакетный менеджер.**
- **`sort`, `contains`, `index_of`, `reverse`** для коллекций —
  через цикл вручную.
- **`break` внутри `switch`.**
- **`init()` без аргументов** — не вызывается.
- **`arr[i] += x`** — пишите `arr[i] = arr[i] + x`.
- **Типизация коллекций** — `list` хранит значения любого типа.

### Планы

- **1.8.1** — фиксы, `sort` / `contains` для коллекций, `for-in`,
  строгая типизация array vs list.
- **1.9.0** — наследование, интерфейсы, лямбды, mark-sweep GC
  для циклов.
- **2.0** — JIT, register allocation, нативная компиляция.

### Известные особенности

- **Циклы ссылок в GC**: если объект A содержит поле-объект B,
  а B — поле-объект A, они не будут освобождены автоматически.
  Это исправится в 1.9.0 через mark-sweep GC.
- **Строки — byte-based**: Unicode-символы вне ASCII могут
  работать некорректно при индексации.
- **`init()` только с аргументами**: `Point()` не зовёт `init`,
  `Point(1, 2)` зовёт.

## Приложение A. Полная программа-пример

```askal
use console;
use string;

class Vec2 {
    var float x = 0.0;
    var float y = 0.0;

    fun init(float x0, float y0) {
        x = x0;
        y = y0;
        return null;
    }

    fun length() -> float {
        return x * x + y * y;
    }

    fun print() {
        console >> print("Vec2(");
        console >> print_float(x);
        console >> print(", ");
        console >> print_float(y);
        console >> println(")");
        return null;
    }
}

fun main() {
    var Vec2 v1 = Vec2(3.0, 4.0);
    var Vec2 v2 = Vec2(-2.0, 5.0);

    v1 >> print();
    v2 >> print();

    console >> print("len_sq(v1) = ");
    console >> print_float(v1 >> length());
    console >> println("");

    v1 >> free();
    v2 >> free();

    var list xs = [1, 2, 3, 4, 5];
    var int64 total = 0;
    for (var int64 i = 0; i < len(xs); i = i + 1) {
        total = total + xs[i];
    }
    console >> print("sum = ");
    console >> print_int(total);
    console >> println("");

    var dict person = {"name": "Alice", "age": 30};
    console >> print("name = ");
    console >> println(person["name"]);

    try {
        throw "test error";
    } catch (e) {
        console >> println("caught");
    } finally {
        console >> println("done");
    }

    return null;
}

main();
```
