# Changelog

## [1.8.0] — 30.09.2026

Первый «полный» релиз языка. Ядро, компилятор, VM, библиотеки,
оптимизация - всё готово.

### Добавлено

**Язык**
- Встроенные коллекции `list`, `dict`, `array` в ядре языка.
- Литералы коллекций: `[1, 2, 3]`, `{"key": value}`, `[]`, `{}`.
- Доступ по индексу: `arr[i]`, `dict["key"]`.
- Присваивание по индексу: `arr[i] = v`, `dict["k"] = v`.
- Встроенные методы коллекций: `push`, `pop`, `insert`, `remove`,
  `clear`, `fill`, `has`, `keys`, `values`.
- Встроенная функция `len(x)` для строк, list, array, dict.
- Ref-counting GC через `std::shared_ptr<VMObject>` в `Value`.
- `free()` теперь снимает ссылку; двойной `free()` безопасен.
- Динамические строки — больше не ограничены 4096 байтами.
- `auto`-переменные больше не ограничены 280-байтной ячейкой.

**Компилятор**
- Constant folding: `2 + 3 * 4` → `PUSH 14`.
- Peephole-оптимизации: удаление бесполезных `JMP`, `PUSH x; POP`,
  мёртвого кода после `RET`/`HALT`.
- Флаги оптимизации `-O0`, `-O1`, `-O2`.
- Обработка `AssignIndexStmt` в codegen.

**VM**
- 16 новых опкодов: `NEW_LIST`, `NEW_DICT`, `NEW_ARRAY`, `INDEX_GET`,
  `INDEX_SET`, `LEN`, `PUSH_ITEM`, `POP_ITEM`, `LIST_CLEAR`,
  `LIST_INSERT`, `LIST_REMOVE`, `DICT_HAS`, `DICT_KEYS`, `DICT_VALUES`,
  `DICT_REMOVE`, `ARRAY_FILL`.
- `DataType::ARRAY/LIST/DICT`.

**Библиотеки**
- `string.dll` — работа со строками (len, substr, to_upper, to_int,
  to_bin, и т.д.).
- `askal_plugin.h` v2: helper'ы `AkReader` / `AkWriter` для разработки
  библиотек.
- Манифесты `*_manifest.json` для всех 9 библиотек.
- `builtins.json` — описание встроенных имён языка.

**Документация**
- `docs/LANGUAGE.md` — полное руководство по языку.
- `docs/syntax.html` — интерактивная шпаргалка по синтаксису.

### Изменено

- Формат `.aklp`: секция `SEC_VARS` использует `Value` вместо
  фиксированных байтовых ячеек.
- `Value` теперь несёт `shared_ptr<VMObject>`, `shared_ptr<VMList>`,
  `shared_ptr<VMDict>`.
- `VM::objects` — `weak_ptr` реестр (не держит объекты).
- `free()` работает как обнуление переменной, а не удаление из VM.
- `do_arith` для `+` конвертирует числа в строку при конкатенации.

### Исправлено

- `auto` без инициализатора — парсер падал на позиции имени.
- `self >> method()` не резолвился в `resolve_in_expr`.
- `is_free_method` не проверялся в `infer_type`.
- `free()` не оставлял значение на стеке — stack underflow.
- `skip_opcode` в VM-лоадере не знал про новые опкоды.
- Объекты как аргументы функций не получали `is_class_object`.
- `str + int` — компилятор падал на смешанных типах.
- `AUTO_CELL_SIZE` рассогласован с компилятором.
- Двойной `free()` вызывал ошибку — теперь no-op.
- `pass2_register_and_resolve` не резолвил `v->init` у полей класса.

## [1.7.0] — xx.07.2026

Полноценное ООП.

### Добавлено

- Классы: объявление, поля, методы.
- Конструктор через `init`.
- `self` в методах (неявный доступ к полям, явный `self >> method()`).
- Объекты как аргументы функций и возвращаемые значения.
- Создание объекта через имя класса: `var Point p = Point(10, 20)`.
- `p >> free()` для освобождения объекта.
- Неявный вызов метода класса изнутри метода (без `self >>`).
- Строковые сравнения (`<`, `>`, `<=`, `>=`).
- Конкатенация с конверсией: `"n = " + 42`, `"flag=" + true`.
- `AUTO`-переменные произвольного типа.

### Исправлено

- `self >> field` в `resolve_in_expr`.
- `self >> field = value` в `resolve_in_stmt`.
- Возврат объекта из функции.
- Объект как аргумент — args получали `is_class_object`.
- `str + int` в codegen и VM.

### Изменено

- Формат `.aklp`: `DECL_VAR` для STR/AUTO использует 4096-байтовую
  ячейку (потом отменено в 1.8.0).
